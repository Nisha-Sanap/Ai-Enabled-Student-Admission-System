# 🎓 AI-Enabled Student Admission System (Salesforce)

## 📌 Project Overview
The **AI-Enabled Student Admission System** is a Salesforce-based application designed to streamline and automate the student admission process.

This system replaces manual and spreadsheet-based workflows with a **centralized, intelligent, and automated platform**, enabling institutions to manage student data efficiently while leveraging AI for smarter decision-making.

---

## 🚀 Features

- 📊 Centralized Student Management  
- 🏫 Course & Enrollment Management  
- 🔐 Role-Based Access Control  
- ⚙️ Automation using Flows  
- ✅ Approval Process  
- 📈 Reports & Dashboards  
- 🤖 AI Integration (Agentforce)  
- 🔍 Duplicate & Validation Rules  

---

## 🧠 Problem Statement

Traditional admission systems face several issues:

- Data duplication due to spreadsheets  
- No centralized system  
- Manual and slow approval process  
- Lack of real-time insights  
- No intelligent decision support  

---

## 🎯 Objectives

- Build a Salesforce-based CRM solution  
- Design custom objects and relationships  
- Implement security (roles, profiles, permissions)  
- Automate workflows using Flows & Approval Processes  
- Enable AI-powered decision making  
- Provide real-time reporting and dashboards  

---

## 🏗️ System Architecture

### 🔹 Custom Objects

- `Student__c`  
- `Course__c`  
- `Enrollment__c`  

### 🔹 Relationships

- Student → Enrollment (One-to-Many)  
- Course → Enrollment (One-to-Many)

## ⚙️ Key Functionalities

### 1. 📥 Student Registration

- Automatic status updates
